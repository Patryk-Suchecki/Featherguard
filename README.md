# Featherguard

An original turn-based mobile game: a party of three birds fights waves of lizards in a nine-battle run. Between battles the run is driven by gambling rewards: a slot machine, double or nothing, card picks, a shop paid in gold or blood and a cursed chest. Feathers earned in each run buy permanent perks at the camp.

Built with Unity 6000.6.2f1 (URP, landscape mobile).
