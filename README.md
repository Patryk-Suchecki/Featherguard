# Featherguard

An original turn-based mobile RPG in a dark Slavic folklore setting: a party of three heroes from the Sacred Oak Stronghold fights through five lands, with timing-based attacks and blocks, a collectable roster and forged equipment. See [docs/GDD.md](docs/GDD.md).

The current build is an earlier prototype (three birds against lizards, with gambling rewards between battles) that is being reworked towards that design.

Built with Unity 6000.6.2f1 (URP, landscape mobile).
