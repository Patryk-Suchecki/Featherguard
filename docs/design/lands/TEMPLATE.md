# <Land>

How the fights in one land play. Copy this file to `lands/<land>.md` (for example `rye-fields.md`) and fill in each section. A land file never decides the roster: which enemies appear here is set by the Bestiary in [`GDD.md`](../../GDD.md#bestiary), and their stages are in [`enemies.md`](../enemies.md). It never covers story missions or side activities either; those belong to the World progression spec.

## Theme

The motif, palette and light of the battlefield, in line with the land's section in [`STYLE_GUIDE.md`](../../STYLE_GUIDE.md#colour).

## Law

The land's Law from the GDD, and how it changes these fights: which enemies it helps, which tactics it punishes.
